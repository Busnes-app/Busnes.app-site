KyVault / Passwords & secrets

Your passwords.
Your vault.

A self-hosted KeePass-compatible vault and synchronization server, with encrypted storage and a browser interface.

Source available · Requires KyIdentity
Read setup guide ↗View source ↗

At a glance

Is it for you?

For people who want an encrypted password vault they can host themselves, and can operate KyIdentity alongside it.

How you use it
A KyIdentity installation is required; KyVault has no local login. Follow the server's configuration guide for identity integration and hosting.
Availability
The server source and setup documentation are available. This page focuses on the documented web experience; consult the repository for client and extension availability.

Inside KyVault

Built with a purpose.

01

KeePass-compatible storage

Your vault is stored as an encrypted KDBX v4 file. Keep a downloaded copy and your offline vault key to open it in a compatible KeePass client.

02

Separate sign-in and unlocking

KyIdentity handles sign-in. Your KyVault master password unlocks the vault key in your browser; it is not sent to the vault server.

03

More than a password list

Organize entries in folders, keep attachments, and inspect or restore previous entry versions when history is enabled.

How it fits together

Know where the pieces live.

Before you get started

Prepare offline access before you need it: retain a downloaded KDBX vault and the Offline Vault Key. If KyIdentity is down, new sign-in is unavailable.

KyDrive / Files & sharing

Your files.
Your hardware.

A self-hosted private and shared drive for small organizations, with versions, trash, quotas and in-browser document editing.

Open source (MIT) · Pilot
Read setup guide ↗View source ↗

At a glance

Is it for you?

For small organizations that want private and shared files on their own hardware instead of a hosted drive, and are comfortable operating a web application.

How you use it
One container built and started with Docker Compose behind your existing HTTPS proxy, with the Euro-Office document editor as a separate service. Kubernetes manifests can be rendered for both.
Availability
In a live pilot. There are no versioned releases yet; each change to the main branch produces a container image. Review the repository for current setup requirements.

Inside KyDrive

Built with a purpose.

01

My files and shared workspaces

Every account gets a private workspace. Shared workspaces open to KyIdentity groups as reader, editor or manager, and access applies to everything inside.

02

Edit documents in the browser

Create Word, Excel and PowerPoint files and edit them in Euro-Office. Markdown, text, CSV and OpenDocument files open there too, and every save becomes a new version.

03

A whiteboard built in

Sketch plans and diagrams in an Excalidraw whiteboard that saves straight into your drive.

04

Nothing lost by accident

Deleted files go to trash and old versions are kept. Managers can purge, administrators can set retention per workspace, and every action is audited.

05

Access that ends when it should

Deactivating someone, removing them from a group or lowering their role ends their file access and open editor sessions.

06

Built on proven parts

Euro-Office for documents, Excalidraw for the whiteboard and restic for file snapshots. Ky supplies the sign-in, workspace permissions and sealed backups that tie them together.

How it fits together

Know where the pieces live.

Know the limits before you rely on it.

KyDrive runs as a single instance with no desktop sync, WebDAV, public links or search yet. The document editor handles files in plaintext, so this is not end-to-end encryption. Back up file blobs with restic to storage that fails independently of the server, alongside capsule backups to KyRecovery.

Read the Busnes.app privacy policy. For data on an independently operated installation, contact its operator.

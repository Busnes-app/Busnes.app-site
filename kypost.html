KyPost / Email

Your mailbox.
Your devices.
Your server.

Read and send mail through your own web interface, keep your existing IMAP and SMTP provider, and pair native clients to your server.

Open source (MIT) · Open beta
Read setup guide ↗View source ↗

At a glance

Is it for you?

For people and small teams who want to run their own email interface while keeping their existing IMAP and SMTP provider.

How you use it
A Linux host with Docker Compose, an IMAP/SMTP account, and a properly secured server address. The browser client ships with the server.
Availability
The server has published container images; Linux has a signed Flatpak remote. Android and Apple distribution have separate release requirements. Check each client repository before downloading.

Inside KyPost

Built with a purpose.

01

Keep your provider

KyPost sits between your existing IMAP and SMTP mailbox and your devices. You do not have to become a mail-delivery operator to use it.

02

Devices never see your password

Scan a QR code from Security, then Devices, in the web app; each code expires after 90 seconds. Every device gets its own credential in the platform keystore. Lose a phone, revoke the phone.

03

Sorting stays home

Filter rules, contacts and the classifier that sorts your inbox run on your server. By default nothing about your mail leaves it for a cloud model.

04

End-to-end when you want it

Your browser generates or imports your OpenPGP key and wraps it before upload. Enroll supported devices to decrypt mail locally. Server-protected key custody is retired; existing legacy keys must be migrated.

05

One option at a time

Turn on device encryption, multi-factor sign-in, local sorting and push delivery when you are ready, not all at once.

06

Choose your client

Native apps pair to your KyPost server rather than directly to an email provider. Release channels, signing and device requirements differ by platform; follow the linked client documentation.

How it fits together

Know where the pieces live.

Server · Open beta
Docker Compose on any Linux host. The quick start covers the environment file, first sign-in and connecting your mailbox.
Web · Included
Ships with the server. Open your server’s address in any browser to read mail, pair devices and change settings.
Android · Development builds
Build a debug APK for evaluation, or use a published signed channel when available. The F-Droid variant needs no Firebase; KyAuth app sign-on currently supports the pinned Play package only. Android setup ↗
Linux · Open beta
A Flatpak for KDE Plasma and Plasma Mobile from KyPost’s own signed remote, for x86_64 and aarch64.
iPhone and Mac · Source builds
Use Xcode on a Mac, with the required signing and device setup. The dependency download is not an installable KyPost app; consult the client repository for application distribution. Apple setup ↗

Before you get started

Connect an existing IMAP/SMTP mailbox to get started; native mailbox receiving is still in qualification. The connection test checks IMAP, so verify sending and receipt separately. Your server stores mailbox credentials and mail data, and its operator manages updates and backups. Optional notification providers process delivery data.

Read the KyPost privacy policy. For data on an independently operated installation, contact its operator.

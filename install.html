Install

Three ways in.
Pick how hands-on you want to be.

Every path ends with the same thing: Ky apps on your own hardware, signing in through KyIdentity, with backups sealed to KyRecovery.

01 · Least effort

Let your AI agent do it

KyQuickStart AI connects your servers over SSH and starts Claude Code, Codex, Gemini CLI or opencode with a tested install prompt. It interviews you once, shows a plan, then works on its own and comes back only for steps a person must do.

git clone https://github.com/Busnes-app/KyQuickStart-AI.git
cd KyQuickStart-AI
./kyqs-ai
  • Linux or macOS with bash, ssh and git
  • Target servers with Docker Engine and Compose
  • A domain you control (LAN-only is fine)

At the end you get a printable sheet of URLs and logins, and a report of every place a README was wrong. Status: first test.

02 · Repeatable

Use the KyQuickStart installer

A command-line installer with prerequisite checks, a plan you review before anything changes, and the same handover sheet. It targets Docker hosts over SSH and existing Kubernetes clusters.

git clone https://github.com/Busnes-app/KyQuickStart.git
cd KyQuickStart && make build
./kyquickstart plan --demo --state ./demo
  • Go, to build from source until a release ships
  • Docker hosts or a Kubernetes cluster you prepared
  • DNS and HTTPS set up as the guided setup describes

The demo plan explores the installer without installing an app. Status: pre-release.

03 · Full control

One app at a time

Every Ky app is its own container with its own README and setup steps. Start with the one you need. Add KyIdentity when you want shared sign-in, and KyRecovery when you want sealed backups.

  • KyIdentity
  • KyPost
  • KyDNS
  • KyRecovery

Every other app is listed on the apps page.

Before you start.

  • You run it, so you own HTTPS, updates, storage and restores. Each README lists what its app needs.
  • An installer handover is not a tested restore. Back up, wipe a test container and restore it before you depend on it.
  • The status board shows which apps are tested and which already run the founder's own setup.
